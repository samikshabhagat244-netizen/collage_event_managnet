# Project Statement

## Project Title
College Event Registration System

## Problem Statement
College events require registration management so that students can register for available events without duplicate entries and organizers can view basic registration information.

## Scope
The system manages event details, participants, registrations, cancellations and reports during a single program session.

## Target Users
- College students
- Student event coordinators
- Faculty/event organizers

## High-Level Features
- Event management
- Participant management
- Event registration
- Registration cancellation
- Capacity checking
- Search
- Reporting
- Validation

## Data Handling
The project uses normal Python lists and dictionaries only. No permanent data storage is implemented. This keeps the project simple and suitable for demonstrating Python programming concepts.
