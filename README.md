# College Event Registration System

## Overview
A modular Python console application for managing college events and registering students for events.

## Main Features
- View available events
- Add a new event during the current session
- Search events
- Register participants
- Prevent duplicate registration
- Check event capacity
- Cancel registration
- Generate registration reports
- Input validation and error handling

## Five Main Functional Modules
1. Event Management
2. Participant Management
3. Registration Management
4. Reporting
5. Validation

## Technologies
- Python 3.x
- Lists and dictionaries
- Functions and classes
- Console input/output
- Unit-style tests

## Data Policy
This project deliberately does NOT use persistent storage.



All information is stored only in Python lists/dictionaries during program execution. When the program exits, runtime data is cleared.
